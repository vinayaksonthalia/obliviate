The problem

Memory that only accumulates is a liability

Agents remember everything and forget nothing. That's fine — until a fact is wrong, hostile, or legally radioactive.

Poisoned facts

A single injected or hallucinated fact propagates through retrieval into every future answer. Once it's embedded and linked, deleting one row isn't enough.

The right to erasure

GDPR Article 17 and CCPA require you to delete a person's data on request — everywhere it lives — and to demonstrate that you did. "We think it's gone" is not compliance.

Unprovable deletion

Ciphertext lingers in MVCC history, replicas, backups, and object storage. Without cryptographic assurance, you can't prove residual data is truly unrecoverable.

How it works

Three proofs, one atomic transaction

Obliviate doesn't just delete. It produces a verifiable, three-part proof around every erasure.

1

It existed

Reconstruct the memory as it stood the instant before deletion — straight from CockroachDB's MVCC history.

SELECT * FROM memory
AS OF SYSTEM TIME t_before
WHERE subject = 'alice';
→ 6 entities recovered
recovered from history
2

It's gone

Query the live database the same way an agent would. Vector search and graph traversal both return nothing.

vector_search('alice') → 0 hits
graph_neighbors('alice') → ∅
ask("what about alice?")
→ "Nothing on record."
live-verified absence

It's irreversible

The subject's data key is crypto-shredded and an object-locked S3 certificate is sealed. Residual ciphertext is unrecoverable — forever.

Capabilities

Built for forgetting that holds up

Every guarantee is enforced in the database, independent of which model does the thinking.

Atomic cross-store cascade

Documents, graph nodes, edges, and vectors are erased in a single CockroachDB transaction. All or nothing — never a half-deleted memory.

Shared-node safety

Entities shared across subjects are retained for the survivors. Forget Alice and Acme Bank stays — because Bob still banks there.

Crypto-shred

Per-subject encryption keys are destroyed on erasure, rendering any lingering ciphertext in history, replicas, or backups permanently undecipherable.

Exhaustive blast-radius

Before deleting, Obliviate maps every document, node, edge, and vector a subject touches — so you see exactly what an erasure will and won't remove.

Bring your own model

Extraction and grounded answering run on any provider — Cerebras, Gemini, OpenAI, or a local Ollama. Forgetting is never coupled to a vendor.

Tamper-evident certificates

Each erasure seals an object-locked S3 certificate and a measured audit event — an immutable trail auditors and regulators can independently verify.
